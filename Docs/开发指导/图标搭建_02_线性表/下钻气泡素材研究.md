# 趋势图节点下钻气泡素材研究

**调研日期：** 2026-11-05
**范围：** 仅使用 `AGENTS.md` 指定的一方素材库（Inspira UI、Uiverse）。目标是为趋势图节点下钻设计“从节点延伸的大气泡”，同时覆盖桌面/手机响应式，以及手机端可拖拽上拉/下拉。

## 来源与可访问性说明

- [Inspira UI 组件目录（官方）](https://inspira-ui.com/docs/en/components?utm_source=chatgpt.com)
- [Uiverse 组件目录（官方）](https://uiverse.io/?utm_source=chatgpt.com)

本次执行环境无法解析上述站点的 DNS，不能把网页截图或在线源码当作已验证事实；以下链接均指向官方页面，需在浏览器中复核具体实现。仓库已有素材调研也记录了同样的限制（Uiverse 页面可能被 Cloudflare 拦截）。因此本文件只把官方页面作为结构/视觉候选，不声称可直接复制其实现代码。

## 先说结论

Inspira UI 更偏动画和视觉组件目录，Uiverse 更偏用户提交的 CSS 片段；两者都不应被当作可访问性完备的 popover/dialog/drawer 基础设施。下钻气泡的交互骨架应沿用项目现有 Vue/Naive UI 能力，素材库只提供外观层次：

1. 桌面端：以图表节点为锚点的 `popover`，保留一条短 leader（连接线/箭头）指回节点；气泡在视口内自动翻转、限高。
2. 手机端：同一内容切换为底部 `drawer`/bottom sheet，顶部拖拽把手支持上拉展开、下拉收起；不要把桌面侧向气泡缩小后硬塞进 390px 视口。
3. 视觉：低对比度海玻璃底、细描边和轻微 spotlight；避免霓虹发光、持续脉冲和厚重阴影，以免压过趋势线。

## 可直接复用的结构（实现时仍需接入项目状态与无障碍）

这些是从“popover/dialog/drawer/anchored bubble”范式提炼出的 DOM/状态结构，适合作为 mRoleScope 的实现契约；不是把 Inspira/Uiverse 代码直接拷贝进项目。

### 1. 锚点气泡（桌面）

- 触发元素是趋势图的实际数据点或其透明命中区，带 `aria-haspopup="dialog"` 和可读的日期/曲线名称。
- 气泡使用 `role="dialog"`（内容包含按钮、筛选或下钻操作时）并由触发点通过 `aria-controls` 关联；纯只读摘要可使用 `role="region"`。
- 气泡外层用 fixed/portal 定位，内部包含标题、日期、岗位数、变化量和“查看明细”操作；最大宽度约 360–420px、最大高度约视口的 60%。
- leader 由单独元素绘制（1px 线 + 小三角），连接点移动时更新，不要把气泡 DOM 嵌入 ECharts canvas。
- 关闭路径至少包括 Escape、点击外部、选择下一个节点；翻转规则应在左右/上下空间不足时切换，而不是让内容溢出视口。

### 2. 底部抽屉（手机）

- 断点建议以可用宽度 600px 左右为起点，并以 390px 真实验收；移动端气泡改为 `position: fixed; inset-inline: 0; bottom: 0` 的 sheet。
- 顶部保留 32–44px 拖拽区与约 36×4px 把手；拖拽区设置 `touch-action: none`，使用 Pointer Events 捕获手指移动。
- 至少提供 collapsed（约 28–35vh）和 expanded（约 78–88vh）两个 snap 点；向下超过阈值或快速下滑关闭，向上超过阈值展开。拖拽过程中给背景图表加遮罩并锁定页面滚动。
- `Esc`、遮罩点击和系统返回键均应关闭；焦点进入 sheet 后保持在 sheet 内，关闭后还原到原始节点。
- 关闭时保留节点高亮一帧再淡出，可帮助用户理解“气泡从哪个节点延伸而来”。

### 3. 节点—气泡连接关系

- 节点被选中时提高描边/光圈，但不要改动曲线颜色语义；leader 使用同色低饱和版本。
- 当气泡被视口边界夹住时，leader 仍指向真实节点（可折线），并显示“已定位到边缘”的稳定位置，避免气泡随每次 pointermove 抖动。
- 同一时间只允许一个下钻气泡；重新点击其他节点应复用容器并更新内容，而不是叠加多个浮层。

## 仅可借鉴的视觉（不复用其交互语义）

### Inspira UI

- [Bubbles Background](https://inspira-ui.com/docs/en/components/backgrounds/bubbles-bg)：可借鉴透明圆泡、慢速漂移和模糊层，作为气泡打开时的极弱背景纹理；不要把动态气泡放在数据文字后面，也不要持续动画。
- [Glow Border](https://inspira-ui.com/docs/en/components/special-effects/glow-border)：可借鉴 1px 渐变边缘或焦点描边，应用在气泡外框/拖拽把手；将发光降至低不透明度，避免与图表高亮竞争。
- [Card Spotlight](https://inspira-ui.com/docs/en/components/cards/card-spotlight)：可借鉴随光标的局部高光，用于桌面端节点和气泡的关联提示；移动端应禁用跟随光标效果。
- [Floating Card](https://inspira-ui.com/docs/en/components/cards/floating-card)：可借鉴轻微悬浮、圆角和层级阴影，作为气泡离开图表平面的空间提示；不要采用大角度透视/持续摆动。

### Uiverse

- [Stepper card](https://uiverse.io/PriyanshuGupta28/orange-newt-23)：可借鉴“节点—竖轨—内容块”的纵向关系，适合气泡中展示日期、岗位数、变化量的顺序；去掉按钮式步骤状态和橙色主题。
- [细描边 Radio](https://uiverse.io/Pradeepsaranbishnoi/wise-snake-15) 与 [极简 Radio](https://uiverse.io/JkHuger/dull-lizard-58)：可借鉴空心圆、内点和细描边的选中提示，用于节点选中态或筛选标签；不能照搬 radio 的可切换语义。
- [Uiverse 官方目录](https://uiverse.io/?utm_source=chatgpt.com)：可继续检索 `tooltip`、`card`、`glass` 等视觉关键词；提交片段质量、键盘支持和响应式行为不一，必须在项目内重写交互。

## 桌面/手机验收建议

| 场景 | 结构 | 关键验收 |
| --- | --- | --- |
| 桌面 ≥1024px | 节点锚定 popover + leader | 气泡不遮住当前节点；靠近边缘时自动翻转；Escape/外部点击关闭；键盘焦点可达 |
| 平板 600–1023px | 较窄 popover，必要时转 bottom sheet | 内容不超过视口 60%；leader 不穿过图例和坐标轴标签 |
| 手机 390px | bottom sheet + 拖拽把手 | 上拉/下拉 snap 稳定；页面不横向滚动；遮罩下图表不响应误触；系统返回可关闭 |
| 触摸/鼠标混合 | 同一状态机处理 pointer 事件 | 拖拽不会触发图表缩放；pointercancel 后状态复位；减少动画偏好生效 |

## 不建议直接采用

- 霓虹发光、强渐变或持续漂浮：会让岗位数和变化量难以扫描。
- Uiverse 片段中未声明 `role`、焦点管理和 Escape 行为的弹层：视觉可借鉴，交互必须重写。
- 把桌面 popover 等比例缩放到手机；手机应切换为 bottom sheet，并保留明确的拖拽把手。
- 在 ECharts canvas 内拼接 HTML 气泡：难以处理焦点、滚动和 390px 视口，建议使用 portal/fixed 容器并将节点坐标映射到视口。

## 后续落地顺序

1. 先用现有 Naive UI/项目状态实现锚点 popover 与 bottom sheet 状态机（含 Escape、焦点和拖拽 snap）。
2. 再从 Inspira 的 Bubbles/Glow Border/Card Spotlight 选择一种低强度边框方案；不要同时叠加多种发光。
3. 最后在 1024px、768px、390px 视口进行真实验收，并以 `prefers-reduced-motion` 关闭漂移和跟随高光。
