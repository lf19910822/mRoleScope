# AI 趋势评测：CVM 真实链路冒烟

该流程只验证线上真实模型、工具调用、流式事件、Serving 读取和审计成本，不属于固定 30 题 benchmark，也不改变发布流程。

1. 使用已授权的 CVM/5175 业务入口，提交完整问题：`比较 Go 和 Python 的岗位数量`。
2. 记录首个操作事件时间、最终状态、工具调用名称与状态、Draft 曲线数量、总耗时和页面显示的 AI 成本/审计数据。
3. 使用只读审计查询核对工具调用次数、输入/输出 token、估算成本和失败职责；不要把线上返回数据复制进固定快照或 benchmark 报告。
4. 将结果保存到独立的 `var/ai-evaluation-smoke/` 或构建产物，并标记 `cvm-smoke`；不要写入 `var/ai-evaluation/` 的固定 benchmark 报告。
5. 若工具或网络失败，只记录失败和安全错误码；不要修改 Serving 数据、日常拉取任务或真实看板。

该文档不包含邀请码、会话令牌、数据库连接串或其他凭据。线上执行由已经完成授权的操作者进行。
