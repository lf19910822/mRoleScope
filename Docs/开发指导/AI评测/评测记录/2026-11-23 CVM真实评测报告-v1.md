- 大量请求在 `batch_trend_summary` 阶段收到 `backend_failure`，因此没有形成最终 Intent 或 Draft。
- 其余部分请求出现 `invalid_combination` 等语义失败。
- 这次结果证明真实模型、工具调用、token usage 和费用记录链路已接通，但不能作为当前 Trend 提示词质量通过的证据。

- 纯指导题和越界题能够完成模型调用，但多次出现 `invalid_enum`，即模型返回内容没有满足 Agent 响应模式契约。
- 混合问题出现 `invalid_combination` 或缺少最终 Intent，未形成通过结果。
- 当前 Agent 评测通过率为 0，需要先修正 Agent 响应契约或提示词，再进行下一轮付费评测。
