# JD 列表与详情一期开发指导

## 本期目标与边界

本期交付可搜索、可筛选、可阅读的 JD 列表与详情页。展示主体始终是 JD，页面读取最新可用数据。

- 范围：JD 列表、筛选、排序、分页、详情页、受控的域名 HTTPS 访问。
- 不在本期：图表总览、日/周/月/季度统计、历史版本对照、JD 正文搜索、同义词或 AI 语义搜索。
- 前端采用 Vue 3、TypeScript、Vite、Vue Router；按需要采用组件库和状态管理。界面实现遵循 `frontend-design` 指引，并以 [Ocean Breeze](./前端资源/ocean-breeze.json) 的浅色 Naive UI Token 为基线：天蓝／青色操作色、填充式控件、充裕圆角和可读的表格间距。方向为轻快、清爽，少量原创卡通／二次元元素，但始终以 JD 信息可读性为先；深色 Token 暂不代表本期必须提供深色模式。

## 分层与数据原则

| 层 | 职责 | 本期约束 |
| --- | --- | --- |
| ODS | 源站原样采集、观察和内容版本 | 不修改采集契约或源数据。 |
| DWD | 版本化的确定性 JD 建模、服务读模型和历史成员关系 | 可增加表、视图、索引与可重试的投影；不可因某项解析失败阻断同步或其他并行处理。 |
| Serving | JD 查询 API、Vue 页面和安全 Web Edge | 只暴露可展示字段，不向用户暴露审计或处理内部细节。 |

服务读模型以最近一次成功发布的源站盘点为锚点，并为每一个已发布运行保留成员与来源版本关系。这既服务本期“最新数据”页面，也为后续按日、周、月、季度、年和自定义范围的版本化图表留下基础。

同一岗位当前内容版本的某一确定性维度尚未完成时，Serving 层可透明回退到该岗位这一维度最新的已完成确定性结果；没有旧结果则展示为无值。该容错不影响其他维度、同步任务或页面展示，且仅保留为后台审计事实，不在页面和图表中提示“待更新”、覆盖率、回退或处理状态。AI 解析结果不进入本期展示读取路径。

## JD 模型字段与筛选口径

页面支持下列分类检索，不提供职责、任职要求或补充说明的正文检索。

| 页面字段 | 数据口径 | 筛选说明 |
| --- | --- | --- |
| 标题 | JD 标题 | 标题包含式、大小写不敏感搜索；支持固定阈值的模糊搜索。精确／包含命中优先于仅模糊命中。 |
| 岗位族 | JD 全部岗位族命中（主岗位族和其他命中岗位族） | 一个筛选器覆盖全部命中；同类多选取并集。 |
| 技术关键词 | 正式、确定性的技术词典结果 | 在下拉菜单中先按技术分类浏览，再按词典顺序多选；输入关键词时始终跨全部分类进行大小写不敏感的包含搜索。 |
| 学历要求 | 确定性学历解析 | 等级为“专科及以下、本科、硕士、博士”；保留上限／下限的语义。 |
| 最低工作年限 | 确定性工作年限解析 | 使用单选下拉框：不限或 `1 年及以上` 至 `9 年及以上`；只表示正式最低工作年限，不把学历换算年限或“优先”项写入其中。 |
| 项目 | 确定性标题项目标签 | 不使用源站 `projectName`。 |
| 工作地点 | 当前 JD 的展示地点 | 按结构化地点筛选。 |
| 活跃状态 | 仍有效／已确认下线／全部 | 默认“仍有效”。待来源复查的暂未出现岗位仍按“仍有效”处理，绝不冒充已下线。 |
| 首次发现日期 | 岗位首次进入系统的日期 | 支持日期条件。 |
| 紧急标记 | 源站紧急招聘标记 | 支持结构化筛选。 |

筛选组合规则固定为：同一字段的多项选择取并集（OR），不同字段之间取交集（AND）。例如选择“后端、AI 应用”两个岗位族，再选择“Python”技术关键词，结果是“任一岗位族命中后端或 AI 应用”且“技术关键词为 Python”的 JD。主岗位族和其他命中岗位族仅在结果卡和详情中分别说明，不作为两个筛选条件。

排序以独立的“排序种类”和“排序方式”两项控件构成：可选种类为最低工作年限、学历要求、首次发现日期、紧急标记、活跃状态和岗位标题。前两项可选从低到高／从高到低；日期可选由早到晚／由新到旧；紧急标记可选非紧急优先／紧急优先；活跃状态可选仍有效优先／已确认下线优先；标题可选正序／倒序。岗位族、技术关键词、项目和地点属于多值集合，只可筛选、不提供人为排序。

用户可依次添加最多四条排序规则，并通过上移、下移决定优先级；每个种类最多出现一次。页面只展示可操作的排序控件，不展示排序实现或数据处理说明。

## 列表与详情体验

- 初始访问展示所有仍有效 JD；用户可切换到“已确认下线”或“全部”。
- 列表使用 `page`、`page_size` 的稳定分页。底部展示页码、每页数量选择与快速跳页；打开详情、返回列表后，已选筛选条件、排序和页码保持不变。不使用 cursor 分页。
- 列表内应用筛选、重置和翻页保持当前滚动位置；从详情通过浏览器返回时优先恢复浏览器保存的位置。
- 详情展示标题、展示元数据、正式建模字段、职责、任职要求，以及存在时的补充说明。
- 岗位族展示为一个“主岗位族”与零至多个“其他命中岗位族”。
- 学历字段名称统一为“学历要求”；显示“专科及以下、本科、硕士、博士”，并在存在上限语义时明确表达。
- 页面不得展示解析器/词典版本、来源或正文版本 ID、审计记录、AI 返回、供应商信息、凭据、覆盖率、回退状态、处理中状态或历史文本差异。
- 应用始终提供左侧导航壳。当前只发布真实可用的“岗位筛选”入口；列表与详情均保持该入口激活，不展示图表、分析等未交付入口。窄屏通过可关闭的菜单和遮罩访问相同导航。

## 性能与 API

Vue 前端通过同源 REST JSON API 读取数据。API 有类型明确的列表、筛选项和详情契约，并使用不透明 JD 标识；不直接将数据库行或内部溯源信息返回浏览器。

服务端应在 DWD/Serving 边界完成版本解析、回退和筛选，不能让页面跨表重建这些规则。查询需采用参数化 SQL、受限页大小、稳定的分页次序，并依据实际 `EXPLAIN (ANALYZE, BUFFERS)` 结果为当前读模型添加索引。索引和服务读模型服务于后续图表，但本期不建设图表页面。

## 域名、HTTPS 与访问控制

本期不再采用裸 IP 公网入口或仅 SSH 隧道预览。最终访问形态为：批准的域名 → HTTPS Web Edge → Vue 静态资源与同源 `/api/` → 内网 Go API → 内网 PostgreSQL。

Web Edge 是唯一可公开监听的服务：它终止 TLS、提供静态页面、反向代理 `/api/`，并在页面与 API 之前启用初期 HTTP Basic Auth 和限流。访问密码仅以 bcrypt 哈希存在 CVM 的 root 所有运行配置中，不进入 Git、镜像层、前端产物或 GitHub Actions 日志。Go API 与 PostgreSQL 不开放公网，也不需要宽松 CORS。

在公开部署前，以下事项必须作为人工发布门槛完成并在运行手册留痕，而不是由代码、CI 或聊天收集敏感信息：

1. 取得域名，完成注册商要求的实名／所有权步骤，并开启账户 MFA 和转移锁；本项目不启用自动续费，需在到期前人工决定是否续费。
2. 由于 CVM 位于中国大陆，确认并完成腾讯云、接入商和监管要求的公网托管前置手续（适用时包括 ICP）。
3. 完成 DNS 所有权和 TLS／认证预检后，才将域名解析到 Web Edge 并开放必要的 80/443；HTTP 仅可用于证书验证或跳转，不提供 JD 数据。

在这些门槛完成前，不改 DNS、不开放端口、不部署公网 Web Edge。完成 DWD、API、Vue、Web Edge 代码与集成验证后，公网发布作为本期最后一步：部署链路需将现有 API、迁移、Worker 的三镜像受控发布扩展为包含 Web Edge 的四镜像不可变 digest 发布，并支持独立回滚 Edge 而不影响同步、历史数据或确定性解析。
