# JD 详情条目索引候选素材调研

**调研日期：** 2026-11-02  
**范围：** 仅考察 `AGENTS.md` 指定的 Inspira UI、Uiverse 素材库；为 JD 详情中的职责/任职要求条目寻找替代“阿拉伯数字实心圆”的信息索引。

## 结论

推荐采用 **空心步骤环 + 极细竖轨**：它保留条目的顺序感，但不会像当前实心蓝色数字圆一样产生按钮感或抢正文注意力。

- 标记直径建议为 `26–28px`，使用 Ocean Breeze 的低饱和 Tide Blue 描边和极浅 Sea Glass 填充；不要使用实心蓝底。
- 数字使用深色小号文本，置于圆心；圆与卡片整体垂直居中。
- 相邻条目之间以一根极细、低对比度的竖轨相连。它只表达阅读顺序，不是可点击步骤控件。
- 现有卡片的轻量 3D 悬停可独立保留；条目索引不承担交互语义。

## 可裁决方案

### A. 无序海玻璃内点

以小号空心圆与中心点代替序号，不显示数字。它最安静，适合本来就没有明确顺序的 JD 条目；阅读顺序由单列列表自然表达。

参考：

- [Uiverse · 细描边 Radio](https://uiverse.io/Pradeepsaranbishnoi/wise-snake-15)
- [Uiverse · 极简 Radio](https://uiverse.io/JkHuger/dull-lizard-58)
- [Inspira UI · Bubbles Background](https://inspira-ui.com/docs/en/components/backgrounds/bubbles-bg)

适配方式：保留空心环和内点的层次，取消 radio 的选中态与脉冲；改为 Sea Glass 浅底、Tide Blue 细描边。

### B. 海玻璃双环数字

保留 `1`、`2` 等条目序号，但改为半透明双环，数字置于中心；各条目之间不连线。相比当前实心圆更轻，仍可快速定位“第几条”。

参考：

- [Uiverse · 双层圆环 Radio（官方源代码）](https://github.com/uiverse-io/galaxy/blob/main/Radio-buttons/ahmed150up_warm-zebra-29.html)
- [Inspira UI · Glow Border](https://inspira-ui.com/docs/en/components/special-effects/glow-border)

适配方式：只借鉴双环结构和极轻的边缘层次；不采用强发光、选中填充或 radio 交互。

### C. 空心步骤环 + 极细竖轨（推荐）

以空心步骤圆表示 `1`、`2`、`3`，相邻圆之间用极细竖轨连接。它兼顾顺序、定位和低干扰，最适合当前“一行一个”的 JD 条目卡片。

参考：

- [Uiverse · Stepper card](https://uiverse.io/PriyanshuGupta28/orange-newt-23)
- [Inspira UI · Bubbles Background](https://inspira-ui.com/docs/en/components/backgrounds/bubbles-bg)

适配方式：只取 stepper 的圆环与竖轨构图；去除橙色、按钮、状态填充和完整步骤面板，避免让纯文本 JD 读起来像操作流程。

## 可配合但不用于编号的效果

- [Inspira UI · Card Spotlight](https://inspira-ui.com/docs/en/components/cards/card-spotlight)：可为整张条目卡片提供很弱的跟随鼠标高光，但应低到不干扰正文。
- [Inspira UI · Glare Card](https://inspira-ui.com/docs/en/components/cards/glare-card)：可与现有悬停层次共存，但不应叠加强烈眩光。
- [Inspira UI · Floating Card](https://inspira-ui.com/docs/en/components/cards/floating-card)：可继续作为当前卡片轻量透视/倾斜的参考；它不解决条目索引本身。

## 不推荐

- 实心、强阴影、霓虹或持续脉冲的圆形控件：会被理解为按钮，且压过 JD 正文。
- Direction-aware、Flip、Fey 等图片导向卡片：它们偏图片覆层、翻面或电影化动效，与结构化文本阅读不匹配。
- 直接搬用 radio/stepper 的交互语义：JD 条目只是只读内容，视觉借鉴不应误导为可勾选或可切换。
