# qwen-plus 北京能力与价格核验

> 核验日期：2026-10-25。仅依据阿里云官方 `qwen-plus` 模型页；价格会调整，首次真实调用前应重新核对。

## 结论

`qwen-plus` 可作为本项目北京业务空间的首期非思考模式基线：官方页在“华北 2（北京）”能力表中列出该模型，并标明“模型体验：支持”“结构化输出：支持”。这是文档能力声明，不等同于已对本账号/API Key 做过实际调用验证。

对本项目受控试跑（单请求上限为 10,000 输入 Token、2,500 输出 Token）适用官方价格表的“输入 <=128k”档。普通（非思考）调用原价为：

| 计费项 | 价格 | 单位 |
| --- | ---: | --- |
| 输入 | ¥0.8 | 每百万 Token |
| 输出 | ¥2 | 每百万 Token |

因此，按每个请求都恰好达到上述项目上限估算，单次 `qwen-plus` 请求的理论价格上限为 **¥0.013**（`10,000 / 1,000,000 × 0.8 + 2,500 / 1,000,000 × 2`）；实际费用取决于实际 Token 用量、缓存及调用方式。此估算不是云账单报价，也不能替代项目中的请求前预算门。

该页显示的最近修改时间为 **2026-10-10**；本次在 **2026-10-25** 读取。它还明确说明页面只展示模型调用原价，限时优惠应以北京百炼控制台为准。
