# 百炼按量 API Key 前缀与权限核验

> 核验日期：2026-10-25。依据阿里云官方中文、英文 API Key 文档与北京控制台的按量付费创建流程；未查看、复制或调用任何真实 Key。

## 结论

百炼按量付费 Key 已完成安全升级（美国弗吉尼亚地域除外）：

| 创建时期 | 格式 | 结论 |
| --- | --- | --- |
| 升级前 | `sk-`，约 32 个字符 | 仍可正常使用。 |
| 升级后 | `sk-ws`，长度较旧格式更长 | 是新版按量付费 Key；明文仅在创建成功时显示一次。 |

因此，在“华北 2（北京）→ 默认业务空间 → API Key → 按量付费”入口新建、且显示为 `sk-ws` 的 Key 可以用于本项目的北京业务空间专属 OpenAI 兼容 Base URL。不要为了追求旧 `sk-` 前缀而重复创建 Key。

中文“套餐类型识别”表仍把 `sk-ws-` 与 Coding Plan 关联；它与新版英文“API key security upgrade”章节冲突。后者直接描述按量 Key 的升级格式，且与当前北京控制台行为一致，故本项目以新版按量 Key 说明为准。

## 最小权限

创建或编辑 Key 时选择“自定义”，开启“访问模型范围”，仅勾选 `qwen-plus` 与 `qwen-flash`。IP 白名单在确认 CVM 固定出口 IP 前保持默认放通；不要猜测或填入不确定的地址。若 Key 已创建但没有模型限制，使用“编辑”补上限制；若未安全保存创建时显示的一次性明文，删除该 Key 后重新创建，而不是试图恢复明文。

## 官方依据

### 1. 按量 Key 安全升级

阿里云官方英文 [How to obtain an API key：API key security upgrade](https://help.aliyun.com/en/model-studio/get-api-key#api-key-security-upgrade)（页面最近修改：2026-10-21）明确说明：升级前按量 Key 以 `sk-` 开头且仍可使用；升级后（美国弗吉尼亚以外）所有新建按量 Key 以 `sk-ws` 开头，且只能在创建时查看明文。该页面明确声明其说明对象是 Model Studio 的按量付费 API Key。

### 2. 按量 Key 与最小模型权限的控制台功能

同一官方页说明，当前 API Key 创建或编辑表单有：

- “归属业务空间”：可选择非默认业务空间，以做权限隔离、精细化模型访问控制或独立成本核算；
- “权限”：可选“自定义”，可配置 IP 与“可访问模型范围”；
- “访问模型范围”开启后，Key 仅能调用已勾选的、且已授权给该业务空间的模型。

对本项目，应将可访问模型范围限为 `qwen-plus`、`qwen-flash`。

### 3. 北京业务空间端点

官方地域文档推荐北京业务空间专属域名 `{WorkspaceId}.cn-beijing.maas.aliyuncs.com`；官方 OpenAI 兼容文档给出的 SDK Base URL 为：

```text
https://{WorkspaceId}.cn-beijing.maas.aliyuncs.com/compatible-mode/v1
```

这两份文档都要求配置 API Key，但没有声明“`sk-ws-` 可作为北京按量付费业务空间 Key”。

- [地域与接入域名](https://www.alibabacloud.com/help/zh/model-studio/regions)
- [OpenAI 兼容 Chat API：北京 Base URL](https://help.aliyun.com/zh/model-studio/qwen-api-via-openai-chat-completions)

## 安全边界

不要把 Key 明文、完整掩码、业务空间 ID 或终端截图发到聊天、Git 或 CI。Key 创建成功后保存到密码管理器；随后只将它写入 CVM 的 root-only 运行时密钥文件，并以无值检查确认两项配置存在。
