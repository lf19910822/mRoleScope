# 技术词典 v0.1 人工审阅表

状态：**项目负责人已完成填写，待实施者生成新词典版本与受控批准清单**。本表是本地政策审阅工作表，不含真实 JD、岗位信息、命中片段或凭据。

## 使用方法

1. **不要修改** [技术关键词归一化映射表 v0.1](technical-keyword-alias-map-v0.1.md)：它是已导入远端候选词典的不可变来源。
2. 只填写各表的“项目负责人决定”和“备注”。推荐决定值为：`批准精确提及`、`保持候选`、`保持条件规则`、`排除`。
3. 同一行中有多个词面的，若只批准其中一部分，请在决定列明确写出，例如“批准：Kubernetes；K8s、K8S 保持候选”。每个词面在远端对应独立规则，不能把“批准整行”误解为自动批准全部别名。
4. 本表的“批准”只表示首期可作**技术词提及**：词面真实出现即记录，不推断它是否为硬性要求、任选关系或实际工作内容。
5. 填完后由实施者把批准项精确映射为 `rule_key`，再调用受控的逐条批准操作；条件词和未批准项不会被启用。

本轮已确认的归并原则：A 表中仅大小写不同的**已登记词面**属于同一技术身份，应一并批准为精确提及；原始词面和证据坐标照实保留，而归一化后的技术身份相同。B 表的“注意大小写健壮性”采用 ASCII 大小写不敏感的**完整名称**匹配，但不会因此接受未登记缩写、相近拼写或子串。对 `Kubernetes`、`K8s`、`K8S` 这类无歧义的全称/缩写组合，也按同一身份处理。
