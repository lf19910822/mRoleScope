# 样本 05：网络 JD 的并列硬性技术与“深入理解”熟练度

## 1. 问题简介与完成环节

该 Plus 结果完成并持久化。总体 3 年经验、本科学历、RDMA 的 P4、Python 的 P3 都有可核验证据；但受控复核为一个技术组记录了 `major_error/alternative_reversal`。

该组的摘要是 `qualification/required/at_least/1`，其引用覆盖 RDMA、RoCEv2 与 InfiniBand 的资格片段。原文没有“或、任一、任选”表达，却以分号/并列方式列出这些协议理解要求；将其展示为“满足任意一项即可”会降低候选人要求。

另有词级熟练度问题：模型对 RoCEv2 与 InfiniBand 给出 P4，原文用词是“深入理解”，而当前受控映射只列出“精通、专家级、深入掌握”对应 P4。

## 2. JD 相关证据片段

> `[jobRequire:s01]` 本科及以上学历；具备 3 年以上超大规模 AI 数据中心网络运维经验，必须具备 1 年以上独立负责 AI 算力集群/HPC 高性能网络调优实战经验

> `[jobRequire:s02]` 精通 RDMA 技术原理，深入理解 RoCEv2 数据包封装结构及 InfiniBand 架构体系

> `[jobRequire:s03]` 对数据中心无损网络的流控机制有深刻理解

> `[jobRequire:s05]` 熟练掌握 Python 或 Golang

> `[addition:s01]` 深入理解 NCCL 底层工作原理，了解集合通信拓扑算法

最后一条位于加分项，不能反向抬升最低学历、硬性年限或硬性技术要求。

## 4. 提示词相关片段

> 清晰并列的 A、B、C 使用 `at_least`，`min_satisfied` 为明确数量；“任一/之一/至少一种/或”为 1。

> 精通/专家级/深入掌握=P4；未明确则 `null`。

> 优先/加分学历不抬高最低学历；技术 option 必须使用 verified 技术命中。
