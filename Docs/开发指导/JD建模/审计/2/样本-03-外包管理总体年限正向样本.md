# 样本 03：外包管理 JD 的总体年限正向样本

## 1. 问题简介与完成环节

这是一份完成的 Plus 结果，不是安全失败样本。它被列入本轮审计，是为了确认第 1 轮已经裁定的“含任选领域时首期保留总体年限”在真实 JD 上是否按预期工作。

受控复核中，经验摘要 `configured/base_year=3` 被接受；最低学历 `not_configured` 也被接受。该结果没有把“外包管理、外包制作或项目管理”分别持久化为三个都需满足的领域项。

## 2. JD 相关证据片段

> `[jobRequire:s01]` 3 年以上外包管理、外包制作或项目管理相关经验，有外包供应商管理经验者优先

> `[jobRequire:s02]` 熟悉程序外包模式，了解工作包拆分、验收与结算流程

> `[jobRequire:s06]` 有游戏开发背景，或游戏研发外包管理经验者优先

JD 没有明确最低学历；“供应商管理经验”和“游戏研发外包管理经验”均带有“优先”。

## 3. Plus 的保存结论（未人工修正）


| 字段       | 模型结论                                                | 当前复核          |
| -------- | --------------------------------------------------- | ------------- |
| 总体经验     | `experience.status=configured`，`base_year=3`，引用年限片段 | `accepted`    |
| 最低学历     | `not_configured`，无证据引用                              | `accepted`    |
| 三个任选经验方向 | 未生成分别的领域年限 item                                     | 与审计/1 的首期口径一致 |




## 4. 提示词相关片段

> 若同一句含 A/B、A 或 B、任选、多个复合领域或无法表达的领域关系，省略所有该句的 domain items，只保留有证据的 `base_year`。

> 优先条件、项目运营年限和非候选人经验不计入必要经验下限。
