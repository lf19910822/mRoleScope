# 技术词典 v0.1 人工确认记录

## 目的与边界

本记录承载项目负责人的**本地词典规则确认**，不含真实 JD、命中片段、岗位名称/ID、原始响应或任何运行时凭据。

它不修改、替代或重新发布 [技术关键词归一化映射表 v0.1](technical-keyword-alias-map-v0.1.md)。映射表是已导入远端候选词典的版本化来源；修改它意味着新的词典内容，必须使用新的版本标签、重新导入、批准、准备候选配置和分析。

首期采用两段式质量门禁：

1. 项目负责人在本地审核“技术身份、可匹配词面、边界和排除关系”等规则政策；
2. CVM 仅对真实正文执行确定性的证据重放校验，且只返回计数、状态、规则键、坐标和哈希等安全元数据。

这套门禁只适用于首期的确定性“技术词提及”指标。它不判断词语是否为硬性要求、任选项或实际工作内容。未来的模糊匹配、上下文消歧、年限/学历抽取等能力，仍必须另设远端人工文本复核门禁。

## 本地人工审核工作表

请在 [技术词典 v0.1 人工审阅表](技术词典v0.1人工审阅表.md) 中批量填写决定。它按技术组汇总全部候选，不要求在对话中逐项回答；若同一组只批准部分词面，应在该行写出精确名称。审核时只看映射表、公开技术语义和不含原文的验收汇总，不要读取或粘贴真实 JD。

只有在工作表中明确写为“批准精确提及”的词面，才可以映射到对应的单个 `rule_key`。条件词、未填写项和保持候选项都不得启用；不要以编辑 v0.1 映射来源的方式修正。
