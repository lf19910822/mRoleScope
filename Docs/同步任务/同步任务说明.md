Docs/同步任务/mihoyo_weekly_sync.py

这是当前每周同步实际使用的版本，**直接请求公开 API，无需 Playwright，也无需第三方 Python 依赖**。已用于10月19日159个岗位的完整采集。

首次运行：

```bash
python mihoyo_weekly_sync.py --output snapshots/current.json
```

与上一轮比较：

```bash
python mihoyo_weekly_sync.py \
  --output snapshots/20261026.json \
  --previous snapshots/20261019.json
```

让 Codex 集成时注意：

- **以实际入口为准**：顶部注释残留旧脚本参数；当前只支持 `--output` 和 `--previous`，实际使用4并发。
- **补存原始响应**：当前输出的是清洗后的完整 JD 字段，未保留全部原始 API 响应。新项目应同时保存原始数据，支持可靠的版本对照。
- **完善差异存储**：当前 `changes` 只记录变化字段名，没有保存旧值或生成 Git 式文本差异。
- **每轮使用不同输出路径**：同路径会被覆盖。脚本不会主动删除上轮快照，历史清理由外部流程负责。
