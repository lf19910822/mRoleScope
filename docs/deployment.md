# 部署方案（未执行）

## 首期拓扑

在用户个人账号下的一台云主机运行反向代理、Go API、worker 和 PostgreSQL；成功批次归档在生产切换为目标云对象存储。公网只开放反向代理的 HTTPS，PostgreSQL 仅在容器或私有网络中可达。定时器调用 worker 命令，不能直接让系统定时器并行运行 Python collector。

## 预算与选择门槛

预算约为每月 100 元，选型时必须分别核验实例、带宽/出站、对象存储、备份、域名摊销和必要附加服务，分别列出首年优惠、续费、年付预付款与月均成本。首期不默认购买托管数据库、负载均衡或付费 CDN。访问者以中国大陆为主，但地域、厂商、域名和备案要求尚未确认，因此不承诺上线时间、不创建付费资源。

## 上线前检查

1. 用户确认云厂商、区域、域名、实际报价和付款方式。
2. 根据届时官方说明核验该区域的域名与上线要求。
3. 配置个人 CI/CD 密钥与运行密钥；禁止提交 `.env` 或向浏览器下发存储/数据库凭据。
4. 配置 HTTPS、最小网络暴露、日志、失败告警、磁盘/对象存储增长告警。
5. 执行数据库恢复和成功批次归档恢复演练。
6. 明确停用或隔离旧 ChatGPT 周扫描任务后，再启用新 worker 的定时器，避免重复采集。
