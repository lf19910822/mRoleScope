# ADR 0002：成功采集批次保留不可变完整归档

状态：已接受（2026-10-20）

## 背景

图表、变更和正文对照都依赖历史原始数据。仅保留最新快照或聚合指标会使后续验证、规则重算和差异解释失去依据。

## 决定

每个成功批次按 `run_id` 保留一份完整、压缩、带 manifest 和 SHA-256 的公开原始响应归档。PostgreSQL 可按内容 hash 去重正文，但 `run_jobs` 必须让每个批次可完整还原。失败临时产物的短期诊断策略与成功归档策略分离。

## 后果

需要持续监控对象存储、磁盘和备份成本，也需要用分阶段提交和孤立产物核对处理对象存储与数据库的非原子性。换来可审计的历史比较与可恢复性。
