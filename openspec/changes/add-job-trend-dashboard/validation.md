## 真实前端验收

2026-11-04 在固定本地入口 `http://127.0.0.1:5175/job-trends` 复验。Vite 只经本机回环 SSH
隧道代理至 CVM Compose 私网 API；浏览器入口仍只有 5175，未暴露 API 或数据库。

- 两个前端代理入口（筛选选项、趋势查询）均返回 JSON HTTP 200。桌面端从真实筛选选项选择
  技术关键词并应用后，浏览器发出实际趋势请求并渲染折线，没有“无法读取可选条件”或行内错误。
- 在 1440px 下通过可见配置控件添加、应用 8 条不同的真实技术曲线：8 条均渲染、无横向溢出，
  图例放在独立底部带，不与 X 轴刻度重叠。长的完整曲线标签通过可滚动图例分页保持可读。
- “全部历史”中，滚轮缩放和鼠标拖拽均会改变可见 X 范围；“复位视图”恢复完整 X/Y 范围，且
  不发起趋势请求。固定预设范围不显示该复位控件。
- 普通站内往返岗位列表与趋势看板后，8 条已渲染曲线和配置恢复，浏览器未重发趋势请求。
- 在 390px 下，标题未截断、页面无横向溢出；“配置曲线”可打开全宽底部面板，8 条配置在面板内
  滚动，不挤压图表布局。
- 当前正式数据中所选真实条件的 14 个历史点恰好没有 `0` 或 `null`。因此没有把不存在的 live
  形态伪装成浏览器验收：`0` 与缺失空档、单条失败保留旧线、缓存和无下钻边界均由趋势 Reader、
  状态模块和图表选项的自动化测试覆盖。真实点击不会改变趋势页路由；节点下钻仍按确认边界搁置。
