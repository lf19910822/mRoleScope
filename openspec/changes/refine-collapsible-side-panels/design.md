# Design

## Visual Direction

以 mRoleScope 的“海洋观测台”作为视觉方向，而不是复制 ChatGPT：侧栏是固定的观测仪表轨道，主内容是观测画布，曲线颜色是右侧轨道上的数据标记。继续使用 ocean-breeze 的海蓝、青绿色和浅色实心表面，避免透明玻璃浮层。

## Decisions

### 1. Desktop shell tracks

- 桌面端使用三段布局：左导航轨道、主内容轨道、右曲线轨道。
- 左轨道宽度为收起 `56px`、展开约 `224px`；右轨道宽度为收起 `48px`、展开约 `320px`。
- 轨道宽度变化同步压缩主内容，不使用固定浮层覆盖图表。
- 侧栏表面使用不透明背景、分隔线和轻微内阴影，保持内容层级清晰。

### 2. Responsive defaults

- `>=1440px`：首次进入时左右侧栏均展开。
- `1100px–1439px`：首次进入时左侧展开、右侧收起。
- `761px–1099px`：首次进入时左右均收起，但保留窄轨道。
- `<=760px`：保留移动端顶部导航抽屉和底部曲线配置面板，不强行使用三列桌面布局。

### 3. Navigation rail

- 收起状态保留独立 SVG 图标、活动态色条和 hover/focus tooltip。
- 展开状态显示品牌、功能名称和现有说明。
- 展开/收起按钮位于导航栏顶部，不使用纵向居中的悬浮“导航”标签。
- 桌面侧栏切换不显示遮罩；移动端抽屉继续使用遮罩。

### 4. Curve rail

- 收起状态为窄色块轨道，每条已配置曲线显示其稳定颜色；无曲线时显示简洁的曲线配置图标。
- 点击色块展开右栏并聚焦对应曲线卡片；顶部按钮只负责展开/收起。
- 展开状态复用现有配置卡片、滚动、编辑、删除和批量操作。
- 删除宽大的纵向居中“配置曲线”按钮。

### 5. Motion and accessibility

- 侧栏轨道和主内容使用约 `260ms` 的平滑宽度过渡，文字使用轻微透明度过渡。
- 不使用 `display: none` 作为桌面开合动画状态；动画完成后通过可见性和交互状态控制不可操作内容。
- 收起/展开后焦点返回对应控制按钮；所有图标入口提供可访问名称。
- `prefers-reduced-motion: reduce` 下取消或极短化过渡。

### 6. State boundary

- 展开/收起状态只存在于当前 Vue 运行时内。
- 不写入服务端、`localStorage`、`sessionStorage`、URL query 或业务 API。
- 页面刷新、重新加载或新会话按响应式默认规则重新决定布局。

### 7. Follow-up rail refinements

- 右侧曲线栏使用与主卡片一致的圆角实体表面；展开态只显示 `×` 关闭按钮，不再同时显示方向箭头。
- 右侧收起态的色标轨道使用固定 `32px` 行高、顶部对齐和 `10px` 间距，不让 CSS 网格隐式行拉伸填满纵向空间。
- `1180px–1439px` 的收起态右栏不再声明 `320px` 固定宽度，始终服从 `48px` 网格轨道。
- `1180px–1439px` 的收起态右栏继续使用紧凑内边距，只有展开态使用配置面板内边距，确保 `32px` 色块在 `48px` 轨道内居中。
- 桌面右栏的色标轨道和配置内容始终挂载，通过透明度、可见性和位移过渡切换，避免 `v-if` 销毁/重建造成闪烁；移动端面板使用同一套可见性过渡并保留现有抽屉入口。
- 左侧导航展开态仅显示向左箭头；收起态不显示展开箭头，点击或键盘激活品牌图标轨道展开导航，并保持头部高度稳定。

### 8. Collapsed marker notes

- 桌面右侧收起态的曲线色块继续保持 `32px` 固定槽位；不同色块之间使用轻量横线分隔。
- 鼠标悬停色块约 `200ms` 后，从色块左侧拉出便签条；便签条复用现有曲线标签格式，例如 `技术关键词 · C++`、`项目 · 智能驾驶`。
- 便签条使用对应曲线色的浅色填充、固定短高度和单行省略，不改变主内容轨道宽度，不遮挡色块名称层级。
- 鼠标移出后立即开始收回，不保留第二个原生 `title` 提示；关闭配置栏后恢复到色块的焦点不展开便签，键盘用户仍通过按钮的可访问名称识别曲线，移动端继续使用点击打开配置面板。

## Verification

- 单元测试覆盖默认布局状态、桌面开合控制、曲线色块展开/聚焦、无状态持久化和移动端回归。
- 视觉验收覆盖 `1440px`、`1280px`、`1100px`、`900px` 和 `390px`。
- 验证展开/收起期间主内容宽度发生变化且没有横向溢出、API 请求重复或数据状态重置。
