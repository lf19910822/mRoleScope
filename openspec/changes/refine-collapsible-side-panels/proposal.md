# Proposal

## Why

当前桌面端左右侧栏使用固定浮层和瞬时显示/隐藏，导航与曲线配置会覆盖图表内容，展开时也不能让主内容自然重排。侧栏入口的视觉权重失衡：左侧重要导航被压缩成悬浮按钮，右侧曲线配置使用宽大的居中按钮，不能形成稳定的工作区结构。

## What Changes

- 将桌面端应用壳层改为“左导航栏—主内容—右曲线栏”的三段布局，侧栏展开/收起通过布局轨道宽度压缩主内容。
- 左导航收起时保留窄图标栏，展开时显示完整名称；使用顶部控制按钮，不再使用页面中央悬浮入口。
- 右曲线栏收起时保留曲线色块轨道，展开时显示现有曲线配置卡片；移除宽大的“配置曲线”悬浮按钮。
- 为两侧栏增加一致的平滑展开/收起动效、焦点恢复、键盘可达性和减少动画支持。
- 采用响应式默认布局：宽屏左右展开，中等桌面右栏收起，紧凑桌面两栏均收起；移动端继续使用现有抽屉/底部面板。
- 不持久化用户的展开/收起选择，不写入服务端、`localStorage` 或 `sessionStorage`。
- 右侧曲线栏保持圆角实体表面；展开态只保留一个关闭控件，收起态曲线色标使用固定高度与顶部等距排列。
- 桌面侧栏切换不通过销毁/重建内容实现；收起态左侧不显示展开箭头，通过品牌图标轨道展开，右侧通过曲线色标展开。

## Impact

- 影响 `web/src/App.vue` 的应用壳层布局和导航视觉结构。
- 影响 `web/src/views/JobTrendView.vue` 的曲线配置栏入口、布局和动画。
- 不改变路由、筛选、曲线数据、下钻、岗位详情或 API 请求语义。
