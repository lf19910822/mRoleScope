# Proposal

## Why

趋势 AI 目前只能读取单维度曲线摘要，无法回答“上海的 Java 岗位有多少”或“游戏引擎相关岗位中哪些岗位族最多”这类需要对同一岗位交叉筛选的问题。用户需要可信的当前统计作为文字回答，同时保留现有单维度趋势图。

## What Changes

- 为技术关键词、项目、岗位族和地点提供当前有效岗位的交叉计数与范围内排名；支持同维度并集、同维度与跨维度交集以及明确的排除条件，并对岗位去重。
- 支持按四个维度分别排名，默认展示前 8 项；用户要求更多或全部时，文字结果不受图表曲线数量限制。
- 由服务端计算并呈现可验证的数量和排名，让 AI 读取相同统计数据并解释；对用户条件、正式值、最终意图和曲线草稿实施范围约束与真正阻断。
- 对含糊的同维度“和”给出各自、并集和交集三种统计；默认包含主、副岗位族，缺少可用技术分析结果的岗位静默跳过。
- 统计和图表独立交付；历史交叉统计暂不支持，明确说明后附带当前结果。图表仍只绘制独立单维度曲线，并说明其与文字统计的区别。
- 本期不提供跨维度并集、历史交叉计算、组合条件趋势曲线或任意 SQL 查询。

## Capabilities

### New Capabilities

- `ai-current-cross-dimension-statistics`: 对当前已发布有效岗位进行受限交叉筛选、去重、分组统计和可信文字交付。
- `ai-trend-scope-validation`: 在每个子问题的条件、正式候选、统计结果和独立曲线草稿上保持用户范围，并阻断未通过校验的输出。

### Modified Capabilities

- 无。当前仓库没有已注册的主规格；已有趋势规划和草稿变更作为兼容性依据。

## Impact

- 影响 Serving 当前岗位筛选与聚合、`internal/aitrend` 意图和工具编排、回复生成及 `internal/httpserver/ai_trend.go` 的受限工具和流式合同；如需承载结构化结果，可能调整趋势页流式消费。
- 保持现有趋势接口、单维度曲线和最多 8 条曲线的能力；当前岗位分析与趋势图可能采用不同时间和岗位族口径，回答须明确区分。
- 沿用已审核的趋势规划提示词工作；模型只接收有界、公开安全的正式标签和聚合数据，不接收 JD 正文、岗位标识、SQL 或凭据。
- 实施前需验证当前岗位身份跨观察范围的去重、结果版本一致性及查询性能；本提案不执行真实模型评测或部署。
