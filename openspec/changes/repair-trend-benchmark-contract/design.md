# Design

- 显式正式值优先于类别：Benchmark 不要求额外 `expected_category`，除非用户问题本身限定了类别。
- 类别查询的范围由 `list_category_values` 工具确认；最终 Intent 使用正式值属于合法结果，scorer 同时接受类别工具证据和正式值表达式。
- `ranking.limit` 仍表示用户请求上限；当类别或全局范围的正式候选不足时，允许模型按实际 Draft 数量返回。显式比较仍要求精确数量。
- v3 快照扩充项目候选至 8 个，v2 继续作为历史评测记录的不可变输入。
- 混合批量摘要保留可用结果，同时在操作事件中携带首个单项安全错误，使错误恢复题可以判定 `unavailable_value` 等边界。
