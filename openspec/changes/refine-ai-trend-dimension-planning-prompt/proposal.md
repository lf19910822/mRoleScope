# Proposal

## Why

趋势规划提示词没有解释四种维度与岗位数量的关系，模型可能把“游戏引擎中哪些技术岗位最多”误解为全局岗位族排名。续轮提示还会在仅返回类别目录时声称候选范围已经确认，与实际工具结果不符。

## What Changes

- 将已审核的维度定义、范围选择和工具规划规则同步至趋势规划提示词。
- 修正续轮提示，要求模型根据用户问题和实际工具结果继续确认范围，不预先声称候选已确认。
- 增加针对实际模型请求的提示词和续轮回归检查，明确当前应用侧仍不能保证类别范围校验或跨轮读取所有批次。

## Capabilities

### New Capabilities

- `ai-trend-tool-planning`: 趋势规划阶段向模型说明维度语义、候选范围和安全工具的适用边界。

### Modified Capabilities

无。当前仓库没有已注册的主规格。

## Impact

- 影响 `internal/aitrend` 的模型规划提示词及其测试和人工审阅文档。
- 不改变工具参数、服务端候选校验、模型工具回合控制、数据库、外部 API 或部署配置。
- 提示词改善模型所接收的指导，不保证模型必然选择正确维度或完成全部候选批次。
