# Proposal

## Why

趋势看板已经能够读取和绘制正式岗位曲线，但用户必须先把自然语言问题手工翻译成结构化曲线条件。项目已有受控的 Qwen、严格结构化校验、正式词典和 Serving 趋势能力，适合在看板上增加一个只负责选择曲线的 AI 草稿层，让用户先看到可编辑结果，再决定是否应用。

## What Changes

- 在趋势看板增加自然语言 AI 作图入口，支持一次请求生成最多 8 条可编辑曲线草稿。
- 新增受控 Go 编排器和固定白名单工具。AI 可自主选择和串联已注册工具，但不能访问 SQL、数据库、JD 正文、密钥或任意新工具。
- 支持技术关键词、项目、岗位族和工作地点。学历、工作年限、直接绘制占比/增长率/事件量曲线以及多维度交集曲线保留为后续能力。
- 支持当前正式技术类别和类别内值、确定性排名、事件摘要、趋势摘要、宽匹配、排除条件、多义词候选和最大努力部分结果。
- 复杂指标只用于确定要画哪些普通 `daily_active_jobs` 曲线，最终每日点位继续由现有 Serving 提供。
- 增加单请求 HTTP 流式 JSON 事件，展示工具名称、过滤后的参数和操作状态。支持停止分析、局部失败继续、参数非法有限重试和用户可见的部分草稿。
- 增加草稿生命周期和并发规则。草稿需用户明确应用，临时保存于当前页面，新请求成功才替换旧草稿，失败或停止保留旧草稿。
- 增加有界的 AI 作图安全审计摘要，保留 30 天且最多 10,000 条，不保存完整用户原文、工具结果、JD 正文或模型原始响应。
- 保持现有趋势接口、正式发布解释、词典同步、缺失日与真实零值语义，不改变当前已应用曲线的自动行为。

## Capabilities

### New Capabilities

- `ai-trend-curve-drafts`: 在趋势看板中把自然语言请求解析为受控、可解释、可编辑并可显式应用的岗位趋势曲线草稿，包含安全工具编排、流式操作反馈、部分成功和草稿生命周期。

### Modified Capabilities

- None. 当前仓库没有已发布的 durable spec。现有趋势看板和 Serving 变更作为实现与兼容性依据读取，不作为本变更的 spec delta。

## Impact

- Go HTTP 层、AI 编排与 Qwen 客户端边界、确定性趋势分析工具、Serving 摘要读取和安全审计摘要存储。
- 趋势看板 Vue 状态、草稿编辑/应用交互、操作记录折叠、单请求流式事件客户端和停止请求。
- 新增 AI 作图请求与流式事件 API，复用现有趋势和筛选数据边界，不开放数据库或内部 API。
- 需要新增针对自然语言意图、工具参数校验、排名口径、匹配取舍、流式状态、并发草稿和审计容量的测试与验证。
