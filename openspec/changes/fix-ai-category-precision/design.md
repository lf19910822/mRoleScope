# Design

## Context

意图提示词虽然提到类别词，但模型仍可能把“编程语言”表示为 `*`；服务层随后按全部技术值扩展。说明模型原先目标为 100 字，真实结果可能刚好撞到上限。

## Goals / Non-Goals

**Goals:**

- 在模型提示和确定性 Runner 两层约束编程语言类别。
- 为说明输出保留长度安全余量。

**Non-Goals:**

- 不改变技术词典、岗位数量排序或候选上限。
- 不新增数据库字段或 API 版本。

## Decisions

- 意图提示词明确给出编程语言类别示例和禁止项。
- Runner 根据中文用户问题识别“编程语言”“数据库”“前端框架”等类别；当模型给出宽泛表达式时替换为类别表达式，继续复用已有词典别名解析。
- 说明提示词要求 80 字以内、完整结束，Provider 仍以 100 字作为硬上限。

## Risks / Trade-offs

- [类别词识别范围有限] → 模型提示继续承担通用理解，Runner 兜底覆盖最常见中文类别。
- [说明变短] → 牺牲少量细节换取完整句子，候选和排序信息仍由草稿保留。

## Migration Plan

1. 通过 TDD 测试提示词和编程语言类别候选。
2. 运行全量质量门并部署。
3. 真实验证编程语言问题只返回语言候选，说明不在句中截断。
