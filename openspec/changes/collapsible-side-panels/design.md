# Design

## Context

应用壳层当前通过固定左侧导航占用 236px，趋势看板通过固定右侧配置栏占用 320–368px。趋势页虽然已经在紧凑桌面使用右侧抽屉，但宽屏仍然默认常驻；两侧固定空间叠加后，用户在阅读主内容时无法主动释放空间。

## Decisions

### 1. 两个面板独立控制

- 左侧主导航与右侧曲线配置使用独立状态，互不影响。
- 两者默认收起，不在主内容布局中预留固定宽度。
- 左侧入口固定在视口左侧，右侧入口固定在视口右侧；入口始终可见且具有可访问名称。

### 2. 复用现有内容与关闭行为

- 左侧继续复用现有路由链接和移动端导航抽屉。
- 右侧继续复用现有曲线卡片、滚动列表、底部批量操作和配置校验。
- 面板打开后显示关闭按钮；Escape、遮罩（移动端）和关闭按钮均可关闭。
- 关闭后焦点回到对应展开入口，避免键盘用户失去位置。

### 3. 内容层不因面板状态跳动

- 面板采用固定浮层，不通过内容缩放或修改业务数据实现收起。
- 趋势主内容在右侧配置关闭时使用完整可用宽度；打开时配置栏覆盖右侧区域，关闭后恢复。
- 岗位详情与趋势下钻的边界使用当前面板占用变量，导航收起时不留下左侧空白。

### 4. 保持移动端适配

- `760px` 及以下继续使用已有顶部导航按钮和底部曲线配置入口。
- 移动端配置仍使用底部面板与遮罩；桌面端不显示遮罩，避免遮暗主阅读区。
- 390px 视口继续验收无横向溢出和入口可达。

## Verification

- 单元测试验证左侧展开/收起、右侧配置展开/收起、焦点恢复和现有路由行为。
- 源码契约测试验证关闭状态不预留两侧布局空间、桌面入口存在、移动端规则未回归。
- Chrome CDP 验收至少覆盖 1440px、1100px、900px 和 390px。
