# Proposal

## Why

趋势看板目前只有宽屏和移动端两档布局，常见笔记本与窄桌面视口仍被固定右侧配置栏挤压，导致图表、事件表格和详情内容过窄，阅读体验明显下降。需要在不破坏现有大屏规划的前提下，为不同桌面宽度提供可读、可操作的布局策略。

## What Changes

- 将趋势看板桌面布局细分为宽屏、标准桌面和紧凑桌面三档，并保留移动端抽屉布局。
- 宽屏继续显示固定右侧曲线配置栏；标准桌面缩小配置栏和工作区间距，但保持双栏结构。
- 紧凑桌面默认释放右侧配置栏占用的空间，改为按需打开的浮层配置抽屉。
- 紧凑桌面显示明确的“配置曲线”入口，并支持打开、关闭、滚动和应用全部曲线。
- 根据桌面宽度调整趋势卡片内边距、图表高度、事件表格密度和详情面板尺寸；不通过整体页面缩放解决适配问题。
- 保持移动端导航、配置抽屉、趋势下钻和岗位详情行为不变，并增加桌面断点与 390px 视口验收。

## Capabilities

### New Capabilities

- `responsive-dashboard-layout`: 为趋势看板及其配置、下钻、详情层提供按视口宽度变化的可读布局和可操作配置入口。

### Modified Capabilities

- 无。

## Impact

- 影响 `web/src/views/JobTrendView.vue` 的桌面 CSS 断点、配置栏展示方式、图表/事件表格/详情层尺寸。
- 可能影响 `web/src/App.vue` 的桌面导航宽度与趋势页可用工作区，不改变导航功能或路由。
- 增加前端布局契约测试、浏览器视口矩阵验收和相关 OpenSpec 验证；不改变 Serving API、数据模型或生产数据。
