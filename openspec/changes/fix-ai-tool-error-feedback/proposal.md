# Proposal

## Why

趋势工具目前把“模型传入的正式值不存在”和“Serving/数据库不可用”混在 `unavailable_value` 或一般失败路径中。工具执行错误虽然会进入历史，但没有明确告诉模型应修正参数并重新选择正式值，导致模型可能绕过失败改用更宽的工具，用户只能看到一次失败操作。

## What Changes

- 增加泛用的模型工具值错误分类，区分无效动态值、固定枚举错误、字段组合错误、结构错误、后端故障和真实结果不可用。
- 将未知类别、未知正式值等模型可修正错误反馈给下一轮模型，并明确要求修正工具参数后重试。
- 保留后端故障的最大努力语义，不把数据库或 Serving 故障伪装成模型参数错误。
- 增加工具服务、编排器和 Qwen 请求协议测试，覆盖未知类别、未知值、枚举错误、后端错误和修正重试。

## Capabilities

### New Capabilities

- `ai-tool-error-feedback`: 为趋势工具定义可区分、可审计且能驱动模型修正重试的错误反馈协议。

### Modified Capabilities

无。

## Impact

影响 `internal/aitrend` 的安全错误码、Serving 工具、Orchestrator、Qwen 工具会话提示词和审计/流事件；不改变公开 API 字段，不读取或修改 JD 数据。已有完整评测和趋势 Draft 契约需要通过回归测试确认兼容。
